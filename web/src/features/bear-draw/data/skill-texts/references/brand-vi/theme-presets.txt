# 配色与字体预设（参考）

> 本文件由小熊API整理，是 `brand-vi` 技能的附属参考。下面的英文段落是开源项目的原文摘录，每段上方标了来源和许可证。许可证全文见 `../../LICENSES/`，致谢清单见 `../../../CREDITS.md`。

## 怎么用

- 这是 Anthropic theme-factory 里 10 套主题中的 5 套，适合做品牌色板的起点。挑一套最接近的，再按品牌改 1–2 个颜色。
- 原文的字体（DejaVu、FreeSans、FreeSerif）是给文档用的西文字体；做中文品牌时只取它的气质（无衬线 / 衬线、粗细），中文落地用可商用字体。
- 都不合适时，照原文 Create your Own Theme 新建一套，起一个能说明气质的名字。

````text
A clean and contemporary theme with a sophisticated grayscale palette for maximum versatility.
````

````text
## Create your Own Theme
To handle cases where none of the existing themes work for an artifact, create a custom theme. Based on provided inputs, generate a new theme similar to the ones above. Give the theme a similar name describing what the font/color combinations represent. Use any basic description provided to choose appropriate colors/fonts. After generating the theme, show it for review and verification. Following that, apply the theme as described above.
````

## 本站调整

- 每套主题只有 4 个颜色。品牌 VI 通常还要一个中性深色（文字）和一个中性浅色（背景），不够就补上，并写清 hex。
- 原文「Best Used For」是海外场景举例，只作参考。
